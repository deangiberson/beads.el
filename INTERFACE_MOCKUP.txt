================================================================================
                            WORKFLOW EXAMPLE
================================================================================

1. User runs: M-x beads-status
   → Opens status buffer showing all issue sections

2. User navigates to an issue and presses 'v'
   → Opens detail buffer with full issue information

3. User presses 'u' to update
   → Transient menu appears

4. User presses 'i' to set status to in_progress
   → Issue updated, buffer refreshes, shows updated status

5. User presses 'q' to close detail buffer
   → Returns to status buffer

6. User presses 'r' to refresh
   → Status buffer updates with latest data

7. User presses 'c' to create new issue
   → Create transient menu appears
   → User selects type (-b for bug), priority (-1 for P1)
   → User presses 'c' to create with title
   → Enters title in minibuffer
   → Issue created, buffer refreshes
